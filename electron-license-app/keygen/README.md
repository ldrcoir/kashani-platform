# ابزار تولید کلید لایسنس (Keygen)

این ابزار برای تولیدکننده نرم‌افزار است تا از روی شناسه دستگاه کاربر، کلید لایسنس معتبر تولید کند.

## نحوه استفاده

### حالت خط فرمان

```bash
node keygen.js <Machine-ID>
```

مثال:

```bash
node keygen.js A1B2C3D4E5F6789012345678ABCDEF01
```

### حالت تعاملی

```bash
node keygen.js
```

سپس از شما شناسه دستگاه پرسیده می‌شود.

## جریان کار

1. کاربر برنامه را اجرا می‌کند.
2. برنامه شناسه دستگاه (Machine ID) را نمایش می‌دهد (یک رشته ۳۲ کاراکتری).
3. کاربر این شناسه را به شما (تولیدکننده لایسنس) می‌دهد.
4. شما با این ابزار از روی شناسه، کلید لایسنس تولید می‌کنید.
5. کلید لایسنس را به کاربر می‌دهید.
6. کاربر کلید را در برنامه وارد می‌کند و لایسنس فعال می‌شود.

## نکات امنیتی مهم

- رشته `LICENSE_SECRET` در فایل `keygen.js` باید دقیقاً با مقدار موجود در `main.js` یکی باشد.
- این رشته باید محرمانه بماند و فقط در اختیار تولیدکننده لایسنس باشد.
- در محیط تولید واقعی، این رشته را با یک ابزار بیلد تزریق کنید و در سورس قابل مشاهده نباشد.
- الگوریتم استفاده‌شده HMAC-SHA256 است که در برابر جعل مقاوم است (تا زمانی که کلید مخفی بماند).
