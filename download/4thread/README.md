راهنمای اجرای برنامه جستجوی عوامل A136030
============================================

پیش‌نیازها
----------

۱. پایتون ۳.۹ یا بالاتر
   - دانلود از: https://www.python.org/downloads/
   - موقع نصب، تیک «Add Python to PATH» را بزن

۲. نصب کتابخانه‌ها
   Command Prompt را باز کن (Win+R → cmd) و این را بزن:

       pip install gmpy2 numpy sympy


روش اجرا
--------

۱. این سه فایل را در یک پوشه کپی کن (مثلاً C:\search\):
   - search_4thread.py
   - A136030_1_to_8000.txt
   - README.md

۲. Command Prompt را باز کن و برو به پوشه:

       cd C:\search

۳. برنامه را اجرا کن:

       python search_4thread.py

۴. برنامه کارهای زیر را انجام می‌دهد:
   - پوشه E:\A136030_Search\ را می‌سازد
   - ۴ نخ به طور همزمان شروع می‌کنند
   - هر نخ روی یک عدد متفاوت کار می‌کند (تقسیم کار)
   - فایل idle.txt هر ۱۰ ثانیه آپدیت می‌شود


تقسیم کار (نه موازی)
--------------------

هر نخ روی یک عدد متفاوت کار می‌کند:
   - نخ ۱: M(1277)  (idx 192)
   - نخ ۲: M(1619)  (idx 241)
   - نخ ۳: M(1753)  (idx 258)
   - نخ ۴: M(2267)  (idx 320)

این روش بهتر است چون:
   - هر CPU هسته روی یک کار مستقل تمرکز می‌کند
   - اشتراک منابع کمتر، سرعت بیشتر
   - اگر یک نخ عامل پیدا کند، بقیه ادامه می‌دهند


فایل‌های ساخته شده در E:\A136030_Search\
----------------------------------------

   - checkpoint.json       چک‌پوینت (موقعیت فعلی هر نخ)
   - idle.txt              نشانه زنده بودن + پیشرفت
   - main.log              لاگ اصلی
   - thread_1.log          لاگ نخ ۱
   - thread_2.log          لاگ نخ ۲
   - thread_3.log          لاگ نخ ۳
   - thread_4.log          لاگ نخ ۴
   - results.txt           عوامل پیدا شده
   - A136030_1_to_8000.txt فایل خروجی (خودکار آپدیت می‌شود)


اگه عامل پیدا شد
----------------

   - در فایل results.txt نوشته می‌شود
   - فایل A136030_1_to_8000.txt خودکار آپدیت می‌شود
   - در فایل idle.txt هم نمایش داده می‌شود
   - در لاگ همان نخ هم نوشته می‌شود


اگه سیستم قطع شد
----------------

   - چک‌پوینت ذخیره شده است
   - دوباره برنامه را اجرا کن
   - از جا مونده ادامه می‌دهد (نه از صفر)


توقف برنامه
-----------

   - در Command Prompt کلید Ctrl+C را بزن
   - یا پنجره را ببند


مشاهده پیشرفت
-------------

   - فایل E:\A136030_Search\idle.txt را با Notepad باز کن
   - می‌بینی هر ۴ نخ کجا هستند و چقدر پیشرفته‌اند
   - مثال:

         === Program is ALIVE ===
         Time: 2026-09-05 10:30:00
         Threads: 4

         --- Progress ---
           idx 192 (M1277): k = 500,000,000 (5.0%), max_q = 1.28e+12
           idx 241 (M1619): k = 480,000,000 (4.8%), max_q = 1.55e+12
           idx 258 (M1753): k = 490,000,000 (4.9%), max_q = 1.72e+12
           idx 320 (M2267): k = 470,000,000 (4.7%), max_q = 2.13e+12

         --- No factors found yet ---


نکات
----

   - برنامه از CPU استفاده می‌کند (نه GPU)
   - ۴ نخ = ۴ هسته CPU
   - اگر CPU خیلی گرم کرد، در فایل search_4thread.py مقدار NUM_THREADS را به ۲ تغییر بده
   - سرعت تقریبی: ۱۰ میلیون k در ۳ ثانیه برای هر نخ
   - برای رسیدن به K=۱۰ میلیارد: حدود ۵۰ دقیقه برای هر عدد
   - همه فایل‌ها با UTF-8 ذخیره می‌شوند (فارسی درست نمایش داده می‌شود)


اگه خطا داد
----------

   ۱. مطمئن شو پایتون نصب است:    python --version
   ۲. مطمئن شو کتابخانه‌ها نصب‌اند: pip list
   ۳. اگه gmpy2 نصب نشد، Microsoft Visual C++ Redistributable را نصب کن
   ۴. اگه باز هم مشکل بود، با من تماس بگیر
