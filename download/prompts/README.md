# 📁 پوشه‌ی پرامپت‌ها

این پوشه شامل پرامپت‌های آماده برای پردازش است.

## نحوه‌ی استفاده:
۱. من (AI) فایل `prompt_XXX.txt` را اینجا می‌گذارم
۲. شما (کاربر) فایل را می‌برید و جواب را برمی‌گردانید
۳. جواب را در فایل `result_XXX.txt` در همین پوشه قرار می‌دهید
۴. من جواب را تأیید/ذخیره می‌کنم

## فرمت فایل پرامپت:
```
# Task: عنوان
# Type: factor / generate / translate / analyze
# Priority: high / medium / low

[محتوای پرامپت]
```

## فرمت فایل جواب:
```
# Result for: عنوان
# Status: success / failed

[محتوای جواب]
```

## نکته:
- این فایل‌ها کاملاً مستقل از کد پلتفرم هستند
- هیچ وابستگی به پروژه ندارند
- فقط داده‌ی خام برای پردازش
