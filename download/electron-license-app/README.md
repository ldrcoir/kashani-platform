# LicenseDemo — برنامه Electron با سیستم لایسنس و دوره آزمایشی

یک پروژه کامل به‌عنوان الگو برای ساخت نرم‌افزار ویندوز با **Electron** که شامل:

- ✅ دوره آزمایشی ۱۴ روزه (Trial)
- ✅ سیستم لایسنس بر پایه **HMAC-SHA256** (مقاوم در برابر جعل)
- ✅ شناسه دستگاه (Machine ID) منحصربه‌فرد برای هر سیستم
- ✅ ابزار تولید لایسنس (Keygen) مستقل
- ✅ رابط کاربری فارسی و راست‌چین (RTL) با تم تیره مدرن
- ✅ فایل **setup.exe** واقعی (NSIS Installer) برای نصب در ویندوز
- ✅ شورتکات در دسکتاپ و منوی استارت + آنینستالر

## 🚀 نحوه استفاده

### ۱) نصب برنامه روی ویندوز

فایل `LicenseDemo-Setup-1.0.0.exe` را روی ویندوز اجرا کنید. ویزارد نصب باز می‌شود و:
- مسیر نصب را می‌پرسد (پیش‌فرض: `C:\Users\<user>\AppData\Local\LicenseDemo`)
- شورتکات دسکتاپ و منوی استارت می‌سازد
- در Add/Remove Programs ثبت می‌شود
- پس از پایان، می‌توانید برنامه را اجرا کنید

### ۲) استفاده از برنامه

۱. برنامه را اجرا کنید. در صفحه اصلی، **شناسه دستگاه** (یک رشته ۳۲ کاراکتری هگز) نمایش داده می‌شود.

۲. در حالت آزمایشی، می‌توانید ۱۴ روز از برنامه استفاده کنید. تعداد روزهای باقی‌مانده و نوار پیشرفت در همان صفحه نمایش داده می‌شود.

۳. پس از پایان دوره آزمایشی، صفحه قفل ظاهر می‌شود و باید لایسنس وارد کنید.

### ۳) تولید کلید لایسنس (برای تولیدکننده)

شما به‌عنوان تولیدکننده، ابزار Keygen را روی سیستم خود نگه می‌دارید (در اختیار کاربر قرار نمی‌دهید).

#### روش ۱ — خط فرمان

```bash
node keygen.js <Machine-ID>
```

مثال:

```bash
node keygen.js A1B2C3D4E5F6789012345678ABCDEF01
```

#### روش ۲ — تعاملی

```bash
node keygen.js
```

سپس شناسه دستگاه را وارد کنید. خروجی چیزی شبیه این خواهد بود:

```
║  شناسه دستگاه (Machine ID):
║  A1B2C3D4E5F6789012345678ABCDEF01
║
║  کلید لایسنس (License Key):
║  DA82C034-4FEB992C-C3074B0A-FE3748C0
```

### ۴) فعال‌سازی لایسنس در برنامه کاربر

کلید لایسنس تولیدشده را به کاربر بدهید. کاربر در برنامه:
1. کلید را در کادر «فعال‌سازی لایسنس» وارد می‌کند
2. روی دکمه «فعال‌سازی» کلیک می‌کند
3. اگر کلید معتبر باشد، برنامه به‌صورت دائمی فعال می‌شود

## 🔐 نحوه کار سیستم لایسنس

### تولید Machine ID

شناسه دستگاه از ترکیب موارد زیر با SHA-256 ساخته می‌شود:

- مدل CPU
- نام هاست (hostname)
- پلتفرم و معماری
- کل حافظه رم
- آدرس MAC آداپتور شبکه (اولین آداپتور غیر داخلی)

خروجی: ۳۲ کاراکتر اول هش (uppercase hex).

### تولید لایسنس

```
License = HMAC-SHA256(MachineID, SECRET).hex().substring(0,32)
        → به فرمت XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX
```

`SECRET` یک رشته محرمانه است که در `main.js` و `keygen.js` یکسان باید باشد. تا زمانی که این رشته مخفی بماند، تولید لایسنس جعلی غیرممکن است.

### اعتبارسنجی لایسنس

برنامه در هر اجرا:
1. Machine ID دستگاه فعلی را محاسبه می‌کند
2. کلید لایسنس ذخیره‌شده در `%APPDATA%\LicenseDemo\license.key` را می‌خواند
3. با استفاده از همان `SECRET`، HMAC را دوباره محاسبه و مقایسه می‌کند
4. مقایسه با `timingSafeEqual` برای جلوگیری از timing attack

### دوره آزمایشی

- در اولین اجرا، timestamp در فایل `%APPDATA%\LicenseDemo\trial.dat` ذخیره می‌شود
- فایل با XOR + Base64 رمزگذاری شده (ضد دستکاری ضعیف، برای دمو کافی)
- جلوگیری از عقب‌کشیدن ساعت سیستم با ذخیره آخرین زمان اجرا
- پس از ۱۴ روز، برنامه قفل می‌شود مگر اینکه لایسنس معتبر وارد شود

## 🛠️ بیلد مجدد (برای توسعه‌دهنده)

### پیش‌نیازها

- Node.js 18+ و npm
- برای بیلد ویندوز از لینوکس: `wine` (یا روش جایگزین که در این پروژه استفاده شد)

### نصب وابستگی‌ها

```bash
cd electron-license-app
npm install
```

### اجرای حالت توسعه

```bash
npm start
```

### بیلد نسخه ویندوز

```bash
# روش ۱: electron-builder (نیاز به wine برای NSIS دارد)
CSC_IDENTITY_AUTO_DISCOVERY=false npx electron-builder --win nsis

# روش ۲: استفاده مستقیم از makensis (بدون نیاز به wine)
# ابتدا نسخه unpacked را بسازید
CSC_IDENTITY_AUTO_DISCOVERY=false npx electron-builder --win dir --config.win.signAndEditExecutable=false
# سپس با makensis اسکریپت installer.nsi را کامپایل کنید
~/.cache/electron-builder/nsis/nsis-3.0.4.1/linux/makensis /home/z/my-project/scripts/installer.nsi
```

## ⚠️ نکات امنیتی مهم (برای محصول واقعی)

1. **مخفی کردن `LICENSE_SECRET`**: در این دمو، کلید در سورس کد قرار دارد. در محصول واقعی باید:
   - با یک ابزار بیلد تزریق شود
   - یا در زمان کامپایل با node-keytar در keyring OS ذخیره شود
   - یا با asar encrypt رمزگذاری شود

2. **استفاده از obfuscation**: کد main.js را با `javascript-obfuscator` مبهم کنید.

3. **استفاده از asar encryption**: فایل asar را با کلید متفاوت رمزگذاری کنید.

4. **برای امنیت قوی‌تر**:
   - از امضای RSA-2048 به جای HMAC استفاده کنید
   - کلید خصوصی RSA فقط در اختیار تولیدکننده باشد
   - کلید عمومی در برنامه برای اعتبارسنجی

5. **ضد دیباگ**: از بسته‌هایی مثل `app-dont-die` یا چک‌های ضد VM استفاده کنید.

6. **تماس با سرور آنلاین** (اختیاری): لایسنس را به سرور مرکزی بفرستید و اعتبارسنجی آنلاین کنید.
