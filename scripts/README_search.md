راهنمای اجرای برنامه ۴-نخی جستجوی عوامل A136030
====================================================

پیش‌نیازها:
-----------
1. پایتون 3.9 یا بالاتر
   - دانلود از: https://www.python.org/downloads/
   - موقع نصب، تیک "Add Python to PATH" رو بزن

2. کتابخانه‌های مورد نیاز:
   Command Prompt رو باز کن (Win+R → cmd) و بزن:
   
   pip install gmpy2 numpy sympy

روش اجرا:
---------
1. فایل search_4thread.py رو در یک پوشه کپی کن (مثلاً C:\search\)

2. فایل A136030_1_to_8000.txt رو هم همون پوشه کپی کن

3. Command Prompt رو باز کن و برو تو پوشه:
   cd C:\search

4. برنامه رو اجرا کن:
   python search_4thread.py

5. برنامه:
   - پوشه E:\A136030_Search\ رو می‌سازه
   - 4 نخ همزمان شروع می‌کنن
   - فایل idle.txt هر 10 ثانیه آپدیت می‌شه (نشونه زنده بودن)
   - چک‌پوینت ذخیره می‌شه (اگه قطع بشی، از جا مونده ادامه می‌ده)

فایل‌های ساخته شده در E:\A136030_Search\:
------------------------------------------
- checkpoint.json    چک‌پوینت (موقعیت فعلی هر نخ)
- idle.txt           نشانه زنده بودن + پیشرفت
- main.log           لاگ اصلی
- thread_1.log       لاگ نخ 1
- thread_2.log       لاگ نخ 2
- thread_3.log       لاگ نخ 3
- thread_4.log       لاگ نخ 4
- results.txt        عوامل پیدا شده
- A136030_1_to_8000.txt   فایل خروجی (آپدیت می‌شه)

اگه عامل پیدا شد:
-----------------
- تو فایل results.txt نوشته می‌شه
- فایل A136030_1_to_8000.txt خودکار آپدیت می‌شه
- تو فایل idle.txt هم نمایش داده می‌شه

اگه سیستم قطع شد:
-----------------
- چک‌پوینت ذخیره شده
- دوباره برنامه رو اجرا کن
- از جا مونده ادامه می‌ده (نه از صفر)

توقف برنامه:
-----------
- Ctrl+C بزن تو Command Prompt
- یا پنجره رو ببند

پیشرفت:
-------
- فایل idle.txt رو با Notepad باز کن
- می‌بینی کدوم idx روی چه k هست
- اگه چیزی پیدا بشه، فوراً ذخیره می‌شه

نکات:
-----
- برنامه از CPU استفاده می‌کنه (نه GPU)
- 4 نخ = 4 هسته CPU
- اگه CPU گرم کرد، می‌تونی NUM_THREADS=2 کنی
- سرعت: ~10M k در 3 ثانیه برای هر نخ
- برای K=10 میلیارد: ~50 دقیقه برای هر عدد
